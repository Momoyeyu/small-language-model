# Boundaries and static publishing

Teaching limits are part of the architecture.

## Model boundaries

- The default Transformer is not automatically upgraded when MoE, RoPE, or QK-Norm is added.
- It is an Encoder–Decoder, not a decoder-only production LLM.
- There is no KV cache, communication stack, or fused kernel path.

## Experiment boundaries

- CartPole cutoff uses finite-horizon termination semantics.
- T5, Shaw, and non-power-of-two ALiBi details are simplified as documented.
- PI/NTK numeric demonstrations are not measured long-context improvements.

`eval_ppl` scores every next-token target except the first on each batch row, requires `stride < ctx`, and restores the original `model.training`. TinyLM uses different BOS alignment and must not be passed in without an adapter.

## Documentation runtime and GitHub Pages

This site is plain static files: an `index.html` shell, the `manifest.json` chapter registry, `chapters/` Markdown, and the Archify-generated `architecture.html`. There is no build step, CDN, external font, or secret. Chapter content is assembled by a lightweight in-browser Markdown renderer; with JavaScript disabled, read the Markdown sources under `chapters/` directly.

```bash
make docs              # local preview on 127.0.0.1:8000; override with PORT
make check-docs        # validate manifest, links, parity, and core import edges
```

GitHub Pages publishes `/docs` from `master`; `.nojekyll` keeps assets untouched. Verify the public directory contains no credentials before publishing; pushing `docs/` changes on `master` redeploys automatically.

## Diagram maintenance

`architecture.html` is generated by [archify](https://github.com/tt-a1i/archify) from `candidate.json`, with node evidence pinned to the source revision recorded in the manifest. When the core structure changes, update the components, edges, and `sources` line numbers in `candidate.json`, then regenerate:

```bash
node archify.mjs finalize architecture docs/candidate.json docs/architecture.html \
  --repo-root . --quality showcase --json
```
