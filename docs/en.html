Overview: one implementation, three consumption lanes

No duplicated core, no hidden experiments, reproducible teaching artifacts.

slm/ is the single core implementation. Scripts, trainers, tests, and notebooks share its public API through from slm import ....

Algorithm primitives, shape contracts, state dictionaries, and the public facade. Dependencies are PyTorch and the standard library.

LANE B / RUNTIMEscripts + trainer

Scripts expose small observable experiments; trainers own long loops, optimizers, and checkpoint workflows.

LANE C / TEACHINGgenerated notebooks

The manifest combines source, demos, and explanation; nbclient records real outputs.

02

Eight core modules and the real dependency graph

Cards record responsibility, primary API, and invariants. Amber borders mark actual internal imports.

slm/common.pyUTILITY

Role
Seeding, consistent display, device selection, and training artifact persistence.
Main API
set_seed, show, get_device, save_run
Invariant
Paths are repository-relative; no model or training algorithm lives here.

slm/envs.pyENVIRONMENT

Role
Hand-written CartPole and Sutton–Barto five-state random walk.
Main API
CartPole, N_STATES, START, walk_step
Invariant
CartPole returns state, reward, terminated, and truncated; the time limit is treated as a finite horizon.

slm/transformer.pySEQUENCE MODEL

Role
Attention, MHA, FFN, masks, embeddings, and the complete Encoder–Decoder.
Main API
attention, MHA, FFN, Transformer
Invariant
Default ReLU dense FFN, sinusoidal PE, nn.LayerNorm Post-Norm, and tied weights. It is not decoder-only and has no KV cache or MoE/RoPE switches.

slm/moe.pySPARSE FFN

Role
Top-K Router, load loss, global expert capacity, and shared/routed experts.
Main API
Router, dispatch, MoELayer, DeepSeekMoELayer
Invariant
Reuses transformer.FFN with GELU. Capacity is ceil(T·K/N·factor), shared across slots with slot priority and no post-drop reweighting. Returns output and aux.

slm/norm.pyNORMALIZATION

Role
Custom BatchNorm, LayerNorm, RMSNorm, and residual-placement blocks.
Main API
BatchNorm, LayerNorm, RMSNorm, PreNormBlock, PostNormBlock
Invariant
Pre/Post blocks reuse RMSNorm locally. QK-Norm is composed in scripts and notebooks, not exposed as a standalone core switch.

slm/position.pyPOSITION

Role
Absolute/relative position, ALiBi, RoPE, length scaling, and sliding-window PPL.
Main API
LearnedPE, ShawRelBias, T5RelBias, apply_rope, eval_ppl
Invariant
Relative examples assume equal Q/K lengths; T5 is clipped and simplified, Shaw is key-relative only; RoPE is split-half with even D. PPL runs no-grad, restores training mode, and covers every target except the first per row.

slm/rl.pyRL PRIMITIVES

Role
Policies, Actor-Critic, returns, rollout, GAE, importance sampling, and PPO loss.
Main API
Policy, ActorCritic, compute_gae, ppo_loss
Invariant
Only reuses the envs.CartPole type/environment. Long training loops stay in trainer.

slm/lm.pyTOY LM

Role
Toy actor/value model with a shared GRU backbone and token log-probability helper.
Main API
TinyLM, token_log_probs
Invariant
TinyLM is a GRU and does not use Transformer. Its BOS-shift alignment differs from a standard causal LM, so it must not be passed to eval_ppl without an adapter.

03

Runtime data flows

Shapes, gradient boundaries, and responsibilities outside each algorithm.

Transformer Encoder–Decoder

INPUTsrc[B,S], tgt[B,T]

padding is passed separately

SHARED FRONTtied embedding + sin PE

source and target share embedding weights

ENCODERmemory[B,S,D]

self-attention + dense FFN

DECODERmasked self + cross

target Q; memory K/V

OUTPUTlogits[B,T,V]

classifier tied to embedding

Text equivalent: source and target pass through a shared embedding and sinusoidal position encoding. The Encoder produces memory. The Decoder performs causal self-attention, cross-attention, and FFN. Training code outside the model shifts next-token labels and masks padding labels with an ignore index.

MoE dispatch

x[T,D]

flattened token batch

router[T,N]

softmax probabilities

topk[T,K]

indices + normalized selected weights

global budget

per expert, shared across slots

output + aux

weighted routed result; optional shared experts

Text equivalent: dispatch consumes each expert's global budget in slot→expert→token order and never renormalizes after drops. Main gradients flow through selected differentiable gates and experts. Discrete top-k indices are not differentiable. The auxiliary loss provides another training path for routing probabilities; under a fixed dispatch mask, probability gradients for unselected experts can be zero.

Text equivalent: PPO first collects fixed old-policy data without gradients, then computes GAE and performs repeated minibatch updates. Toy RLHF freezes a reference and combines a rule-based score with sampled log-ratio KL rewards. No hidden benchmark or convergence guarantee is implied.

First-occurrence rule: FFN is expanded as a real source cell in EP.0. EP.1 imports it and shows how MoE reuses it. Supporting training and plotting loops stay as literal manifest code instead of being pushed into core for generator convenience.

The checker compares each cell type and source against regeneration, then checks the recorded whole-core SHA. Even when a chapter only imports an earlier symbol, any core change invalidates all notebooks.

05

Extend a teaching capability

Define invariants first, then keep demos, tests, and teaching artifacts synchronized.

  1. Choose the core home. Put a reusable mathematical primitive in the closest slm module. Do not create imports merely to match notebook order.
  2. Publish the API. Re-export it explicitly from slm/__init__.py; consumers continue using from slm import ....
  3. Add a focused test. Prefer formulas, shapes, gradients, capacity, and state restoration over fragile one-run performance numbers.
  4. Add a small demo. Numbered scripts use show(name, value) for key observations. Long training loops belong in trainer.
  5. Place the first lesson. Add source to tools/chapters.py in dependency order. Later chapters import it instead of duplicating it.
  6. Rebuild and verify. Install notebook extras, execute every notebook, check freshness, then run focused tests. Enable slow convergence fixtures when appropriate.

Minimal public API usage

from slm import FFN
import torch

layer = FFN(16, 32)
y = layer(torch.randn(2, 8, 16))

This only constructs a reusable token-wise FFN. The consumer owns data, optimizer, loss, and training loop.

06

Boundaries and static publishing

Teaching limits are part of the architecture.

Model boundaries
  • The default Transformer is not automatically upgraded when MoE, RoPE, or QK-Norm is added.
  • It is an Encoder–Decoder, not a decoder-only production LLM.
  • There is no KV cache, communication stack, or fused kernel path.
Experiment boundaries
  • CartPole cutoff uses finite-horizon termination semantics.
  • T5, Shaw, and non-power-of-two ALiBi details are simplified as documented.
  • PI/NTK numeric demonstrations are not measured long-context improvements.

eval_ppl scores every next-token target except the first on each batch row, requires stride < ctx, and restores the original model.training. TinyLM uses different BOS alignment and must not be passed in without an adapter.
